Voltask

Voltask je platforma na evidenciu tímov a úloh, ktorá vzniká ako alternatíva k nástrojom ako Jira alebo Trello. Je optimalizovaná priamo pre potreby predmetu Tímový projekt, aby študenti aj učitelia mali prehľad o práci tímov na jednom mieste.

Hlavné funkcie:

  • vytváranie tímov a pridávanie členov
  • Kanban nástenka s úlohami v stĺpcoch To Do, In Progress a Done
  • prideľovanie úloh členom tímu a sledovanie aktivity
  • real-time aktualizácia úloh vďaka WebSocketom
  • notifikácie cez webhooky do fakultného Discordu alebo Slacku, napríklad „Jozef dokončil úlohu X“
  • prehľad všetkých tímov a ich progresu pre učiteľa

Použité technológie:

  • Frontend: TypeScript + React
  • Backend: TypeScript + Node.js + NestJS + Socket.IO
  • Databáza: PostgreSQL + Prisma
  • Ostatné: JWT autentifikácia, Discord webhook, Docker Compose, GitHub Actions

Harmonogram

Prehľad fáz

Trvanie projektu: 11 týždňov (aktívny vývoj 9 týždňov, rezerva 2 týždne)

Fáza Trvanie Týždeň Hlavný výstup
1. Iniciácia projektu 1 týždeň 1 Zadanie, rozdelenie rolí, nastavenie komunikácie
2. Analýza požiadaviek 1 týždeň 2 SRS dokument, ERD model databázy
3. Návrh riešenia 1 týždeň 3 Architektúra systému, návrh databázy a API, návrhy obrazoviek
4. Implementácia – backend (I.) 2 týždne 4–5 Databáza (Prisma), JWT autentifikácia, tímy a úlohy (REST API)
5. Implementácia – frontend (I.) 2 týždne 4–5 Základné UI (prihlásenie, prehľad tímov), Kanban nástenka
6. Implementácia – backend + frontend (II.) 2 týždne 6–7 Real-time aktualizácie (WebSockety), Discord webhook notifikácie, pohľad učiteľa
7. Testovanie a ladenie 1 týždeň 8 Testovací plán, opravy chýb
8. Nasadenie a dokumentácia 1 týždeň 9 Nasadenie (Docker Compose), používateľská dokumentácia
9. Rezerva 2 týždne 10–11 Finálne úpravy, prezentácia projektu

Milníky

  • M1 – schválenie analýzy (koniec 2. týždňa)
  • M2 – hotový návrh UI a databázy (koniec 3. týždňa)
  • M3 – hotový backend a základný frontend (koniec 7. týždňa)
  • M4 – testovanie a opravy chýb (koniec 8. týždňa)
  • M5 – nasadenie, dokumentácia a prezentácia (9.–11. týždeň)
