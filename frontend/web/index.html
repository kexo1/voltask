Voltask

Voltask je platforma na evidenciu tímov a úloh, ktorá vzniká ako alternatíva k nástrojom ako Jira alebo Trello. Je optimalizovaná priamo pre potreby predmetu Tímový projekt, aby študenti aj učitelia mali prehľad o práci tímov na jednom mieste.

Hlavné funkcie:

  • vytváranie tímov a pridávanie členov
  • Kanban nástenka s úlohami v stĺpcoch To Do, In Progress a Done
  • prideľovanie úloh členom tímu a sledovanie aktivity
  • real-time aktualizácia úloh vďaka WebSocketom
  • notifikácie cez webhooky do fakultného Discordu alebo Slacku, napríklad „Jozef dokončil úlohu X“
  • prehľad všetkých tímov a ich progresu pre učiteľa

Použité technológie:

  • Frontend: TypeScript + React
  • Backend: TypeScript + Node.js + NestJS + Socket.IO
  • Databáza: PostgreSQL + Prisma
  • Ostatné: JWT autentifikácia, Discord webhook, Docker Compose, GitHub Actions
